## How to Add Entries

When making changes, add entries under `[Unreleased]` with the appropriate section:
- **Added** — New features
- **Changed** — Changes to existing functionality
- **Fixed** — Bug fixes
- **Security** — Security-related changes

When releasing a new version, move `[Unreleased]` to `[x.y.z] - YYYY-MM-DD` and add a new `[Unreleased]` section.
